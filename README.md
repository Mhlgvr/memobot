# Memobot 🤖

**Memobot** — учебный проект, написанный в рамках летнего буткемпа Центрального университета. Главная фича -- бинарная классификация картинки-мема по соответствию стилистике группы. Не спрашивайте зачем, по легенде нас попросил админ вк-паблика сделать такого бота, чтобы все посты в канале проверялись на соответствие стилистике перед публикацией. 
Доп фичи -- предсказание количества лайков, репостов и просмотров и генерация мема. Да, я знаю, юмор не предсказуем, а сгенерировать понятный мем модель не сможет, но все равно это прикольно. 

## Блоки проекта 🚀

- **Telegram-бот**:
  - Разбирается в мемах (например, понимает, из какой группы мем)
  - Предсказывает популярность (сколько лайков, репостов и просмотров наберет)
  - Выбирает лучшую модель для анализа (ResNet или EfficientNet)
  - Удобное меню и обработка картинок прямо в чате

- **Нейросети**:
  - Классификаторы мемов на базе ResNet и EfficientNet
  - Регрессоры для предсказания лайков, репостов и просмотров
  - Скрипты для работы из командной строки

- **Парсинг данных**:
  - Ноутбуки для сбора постов и картинок из ВКонтакте
  - Подготовка данных для обучения моделей

## Запуск 📦

1. **Скачай проект:**
   ```bash
   git clone <repo_url>
   cd memobot
   ```

2. **Установи зависимости:**
   ```bash
   # Если не установлен poetry, надо сначала его установить:
   curl -sSL https://install.python-poetry.org | python3 -

   poetry install
   ```

3. **Настрой переменные окружения:**
   - Создай файл `.env` в корне проекта и добавь токен своего бота:
     ```
     TOKEN=твой_токен_бота
     ```

4. **Скачай веса моделей:**
   - Обучаем модели по ноутбукам где-нибудь в колабе и скачиваем файлы с весами, их надо положить в папки `data/classification/` и `data/regression/` (смотри пути в `models/`).

## Как запустить бота? 🚀

```bash
python scripts/start_bot.py
```

## Работа из командной строки 💻

- **Классификация мемов:**
  ```bash
  python scripts/classify.py --model resnet путь/к/картинке.jpg
  ```
- **Предсказание популярности:**
  ```bash
  python scripts/predict.py --model efficientnet путь/к/картинке.jpg
  ```

## Обучение моделей 🧠

Процесс обучения описан в ноутбуках:
- `notebooks/classification_models_training.ipynb` - Обучение моделей классификации
- `notebooks/regression_models_training.ipynb` - Обучение моделей регрессии
- `notebooks/parse_data.ipynb` - Парсинг данных из ВКонтакте

## Зависимости 📚

- **Python**: >=3.12
- **aiogram**: >=3.21.0,<4.0.0 (фреймворк для Telegram-ботов)
- **torch**: >=2.7.1,<3.0.0 (PyTorch - для нейросетей)
- **torchvision**: >=0.22.1,<0.23.0 (компьютерное зрение)
- **dotenv**: >=0.9.9,<0.10.0 (переменные окружения)
